All Streamshade feature logic, including the adapted VAFT engine, is bundled in the submitted ZIP. The player integration wraps classic same-origin blob workers created by Twitch and uses importScripts to load the original Twitch-supplied blob worker so normal player execution can continue. That Twitch code is not part of the extension package. It runs in the website's worker context without extension APIs. No blocker scripts, extension feature logic, or executable updates are downloaded from GitHub or another remote service. Please assess this website-worker integration under the MV3 exemption for contexts isolated from extension APIs. The bundled source shows the wrapper, settings bridge, and playback modifications.
